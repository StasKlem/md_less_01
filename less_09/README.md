# Суммаризация контекста

Приложение автоматически сжимает длинную историю диалога в краткое резюме, чтобы не превысить лимит токенов модели.

## Как работает суммаризация

### 1. Когда запускается

Суммаризация запускается **перед каждым отправкой нового сообщения** в чат:

```
Пользователь отправляет сообщение
         ↓
   Создание summary (если нужно)
         ↓
   Отправка в LLM для получения ответа
```

### 2. Условие создания summary

Summary создаётся, когда количество сообщений пользователя и ассистента превышает порог (по умолчанию 10 сообщений).

Это можно настроить в Settings → Summarization Strategy → Keep Last N Messages.

### 3. Процесс создания summary

```
1. Проверка: достаточно ли сообщений для суммаризации?
         ↓
2. Получение всех сообщений, кроме последних N (N = messagesToKeep)
         ↓
3. Отправка в LLM с системным промптом суммаризации:
   "Проанализируй диалог и создай краткое резюме..."
         ↓
4. Сохранение summary в сессию и storage
         ↓
5. При следующих запросах summary подставляется в начало контекста
```

### 4. Формат запроса на суммаризацию

```json
{
  "model": "llama3.2",
  "messages": [
    {"role": "system", "content": "Ты - ассистент для суммаризации..."},
    {"role": "user", "content": "Резюме предыдущего контекста: [ПРЕДЫДУЩЕЕ_РЕЗЮМЕ]\n\nНовые сообщения:\n[сообщения для суммаризации]"}
  ]
}
```

Если предыдущего summary нет — отправляются все сообщения без него.

### 5. Использование summary в чате

После создания summary, при отправке нового сообщения:

```json
{
  "messages": [
    {"role": "system", "content": "[Системный промпт пользователя]"},
    {"role": "system", "content": "Резюме предыдущего контекста: [SUMMARY]"},
    {"role": "user", "content": "[Последнее сообщение пользователя]"},
    {"role": "assistant", "content": "[Последний ответ ассистента]"}
  ]
}
```

Последние N сообщений остаются "как есть", остальные заменяются на summary.

### 6. Где хранится summary

- **В памяти**: `ChatSession.conversationSummary`
- **Перманентно**: `ConversationSummaryStorage` (UserDefaults)

## Настройки суммаризации

В Settings доступны:

| Параметр | Описание |
|----------|----------|
| **Strategy** | `none` (отключено) или `keepLastMessages(N)` |
| **Keep Last N Messages** | Количество последних сообщений для хранения |
| **Summarization Prompt** | Системный промпт для LLM |

## Пример работы

```
Сообщений в чате: 15
messagesToKeep: 10

До суммаризации:
[msg1][msg2][msg3][msg4][msg5][msg6][msg7][msg8][msg9][msg10][msg11][msg12][msg13][msg14][msg15]

После суммаризации:
[SUMMARY][msg6][msg7][msg8][msg9][msg10][msg11][msg12][msg13][msg14][msg15]
            └──────── keepLastMessages(10) ────────┘
```

## Подсчёт токенов

Приложение поддерживает подсчёт токенов на трёх уровнях:

### 1. Токены текущего запроса

Для каждого запроса к модели отображаются:
- **Prompt Tokens** — количество токенов во входном сообщении (ваш запрос + история диалога + системный промпт)
- **Completion Tokens** — количество токенов в ответе модели
- **Total Tokens** — сумма prompt + completion

**Откуда берутся данные:**
- API LLM (Ollama, OpenAI, LM Studio) возвращает объект `usage` в ответе
- Для streaming-режима данные приходят в последнем чанке
- Для non-streaming режима данные приходят сразу в ответе

### 2. Токены ответа модели

Токены ответа (completion tokens) сохраняются:
- В каждом сообщении (`Message.completionTokens`)
- В истории диалога (накапливаются при сохранении контекста)
- В метриках текущего запроса (отображаются в реальном времени)

### 3. Токены всей истории диалога

Накапливаются в течение сессии:
- **Conversation Prompt Tokens** — сумма всех prompt tokens за все запросы
- **Conversation Completion Tokens** — сумма всех completion tokens за все ответы
- **Conversation Total Tokens** — общая сумма токенов диалога

**Важно:**
- Счётчики диалога сбрасываются при нажатии "Clear Chat"
- При сохранении контекста токены сохраняются вместе с сообщениями
- При перезапуске приложения токены подхватываются из сохранённых сообщений

                            ↓
┌─────────────────────────────────────────────────────────────┐

## Структуры данных

### Message
```swift
struct Message {
    var promptTokens: Int?      // токены запроса
    var completionTokens: Int?  // токены ответа
    var totalTokens: Int?       // общие токены
}
```

### RequestMetrics
```swift
struct RequestMetrics {
    // Текущий запрос
    var promptTokens: Int
    var completionTokens: Int
    var totalTokens: Int
    var tokensPerSecond: Double
    var requestDuration: TimeInterval
    
    // История диалога
    var conversationPromptTokens: Int
    var conversationCompletionTokens: Int
    var conversationTotalTokens: Int
}
```
