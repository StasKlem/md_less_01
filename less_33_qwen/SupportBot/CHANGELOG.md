# Changelog

Все значимые изменения проекта SupportBot.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
версионирование по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] — 2026-04-03

### Добавлено

#### Файловые инструменты
- **Чтение файлов** (`/files <path>`) — просмотр содержимого файлов проекта с нумерацией строк
- **Поиск в файлах** (`/search <pattern> [path]`) — regex-поиск по содержимому файлов
- **Список директорий** (`/list [path]`) — просмотр файлов и директорий с иконками
- **Анализ проекта** (`/analyze`) — полный анализ структуры: статистика, дерево, зависимости, рекомендации
- **Проверка инвариантов** (`/invariants`) — проверка соответствия правилам (README, LICENSE, тесты, точка входа, TODO)

#### Новые компоненты
- `FileService.swift` — сервис для работы с файлами (чтение, поиск, создание, изменение, diff)
- `ProjectAnalyzer.swift` — анализатор проекта (статистика, структура, зависимости, инварианты)
- `FileTool.swift` — модель инструментов и результатов выполнения

#### Обновления промптов
- Новый системный промпт для файлового ассистента (`fileAssistantSystemPrompt`)
- Промпт для анализа кода (`buildCodeAnalysisPrompt`)
- Промпт для генерации содержимого файлов (`buildFileContentPrompt`)
- Промпт для файлового ассистента (`buildFileAssistantPrompt`)

#### Команды
- `/files` — прочитать файл или директорию
- `/search` — поиск по содержимому файлов
- `/list` — список файлов в директории
- `/analyze` — анализ структуры проекта
- `/invariants` — проверка соответствия правилам

### Изменено

- `SupportBotService.swift` — добавлены файловые инструменты и метод `executeTool(tool:arguments:)`
- `App.swift` — обновлена версия до 1.1.0, добавлены новые команды и статусы
- `PromptBuilder.swift` — добавлены новые методы построения промптов
- `config.example.yaml` — добавлена секция `file_tools` с настройками
- Версия приложения обновлена с 1.0.0 до 1.1.0

### Улучшения

- Статус "печатает" при выполнении файловых операций
- Форматированный вывод результатов с иконками и метаданными
- Ограничение размера файлов для чтения (1MB)
- Фильтрация скрытых файлов и директорий (.build, DerivedData)
- Поддержка относительных и абсолютных путей

## [1.0.0] — 2026-04-02

### Добавлено

#### Основная функциональность
- **RAG пайплайн** — индексация базы знаний и генерация ответов с контекстом
- **TUI интерфейс** — текстовый интерфейс с историей чата и информационной панелью
- **База знаний** — поддержка Markdown файлов в KnowledgeBase/
- **Конфигурация YAML** — гибкая настройка через config.yaml
- **Контекстная память** — история диалога с SQLite
- **Множество LLM провайдеров** — OpenAI, RouterAI, локальные API (Ollama, LM Studio)

#### Компоненты
- `SupportBotService.swift` — главный сервис (оркестратор)
- `ChatService.swift` — управление чатом и сессиями
- `RAGService.swift` — RAG пайплайн (поиск + генерация)
- `ContextManager.swift` — управление контекстом диалога
- `ConfigManager.swift` — загрузка и парсинг YAML конфигурации
- `OpenAIProvider.swift` — реализация LLM провайдера (OpenAI-совместимый API)
- `PromptBuilder.swift` — построение промптов с контекстом
- `ChatHistoryDB.swift` — SQLite история чата
- `DocumentDB.swift` — SQLite база документов
- `VectorStore.swift` — SQLite векторное хранилище
- `DocumentIndexer.swift` — индексация Markdown файлов
- `OpenAIEmbedding.swift` — OpenAI embedding модель
- `LocalEmbedding.swift` — локальная embedding модель

#### Команды
- `/help` — справка
- `/clear` — очистить историю
- `/new` — новая сессия
- `/index` — переиндексировать базу знаний
- `/status` — статус сервиса

### Технологии

- **TUI**: TauTUI
- **HTTP**: AsyncHTTPClient
- **БД**: SQLite.swift
- **YAML**: Yams
- **Логирование**: swift-log
- **LLM**: OpenAI API (GPT-4o-mini, DeepSeek)
- **Embeddings**: OpenAI API, локальные модели
