# Функции SupportBot

## 🤖 Умные ответы

SupportBot использует RAG (Retrieval-Augmented Generation) для предоставления точных ответов на основе вашей базы знаний.

## 📚 База знаний

Поддерживает документы в формате Markdown:
- FAQ
- Документация
- Инструкции

## 💬 Контекстная память

Помнит контекст диалога:
- Последние 10 сообщений
- Учитывает предыдущие вопросы

## 🔍 Поиск по документации

Автоматически находит релевантные фрагменты документов и использует их для генерации ответа.

## 🎨 TUI интерфейс

Красивый текстовый интерфейс с:
- Историей сообщений
- Информационной панелью
- Поддержкой клавиш навигации

## ⚙️ Гибкая конфигурация

Настройка через YAML-файл:
- Выбор LLM провайдера
- Параметры RAG
- Настройки логирования
